**Instalacja:** Foundry → Game Systems → Install System → Manifest URL:
`https://github.com/morgir/degenesis2/releases/latest/download/system.json`
Aktualizacja: przycisk **Update** przy systemie.

## Zmiany w tej wersji
- Nowy dziennik MG **„Muzyka do sesji (Spotify, YouTube)”** w kompendium przygody: playlisty i albumy według nastroju oraz tabela „co kiedy” dla „Cichych studni”.
- **Stałe ID dokumentów w kompendiach.** Od tej wersji te same dokumenty mają to samo ID w każdym wydaniu, więc instalator przy aktualizacji pomija to, co już masz w świecie, zamiast tworzyć duplikaty.
- Jednorazowo: jeśli zainstalowałeś zawartość z 0.6.1 lub 0.6.2, przy tej aktualizacji zaznacz w instalatorze tylko nowe rzeczy albo usuń stare foldery przed instalacją.
